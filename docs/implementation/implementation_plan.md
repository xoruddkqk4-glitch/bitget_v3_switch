# 더미(2차) 및 실제 매수(10차) 노란색/검정색 고대비 인디케이터 구현 계획서

본 문서는 사용자의 요청에 따라 가시성을 극대화하기 위해, **노란색 네모(`🟨`)**와 **검정색 네모(`⬛`)**의 고대비(High-Contrast) 색상 조합을 적용한 **단일 트랙 하이브리드 차수 인디케이터**를 구현하기 위한 계획서입니다.

> [!IMPORTANT]
> **모드 정책 준수 안내 (`/ask` 전용)**
> 본 문서는 `/ask` 규칙에 따라 작성된 계획서이며, **프로젝트 소스 코드를 아직 수정하지 않았습니다**.  
> 계획서 검토 후 사용자가 **`/apply`** 명령어를 입력하시면 본 계획서에 정의된 단계에 따라 실제 소스 코드 반영 및 터미널 정적 검증(`py_compile`)이 즉시 집행됩니다.

## 1. 노란색(`🟨`) & 검정색(`⬛`) 고대비 디자인 채택 배경

1. **텔레그램 Bot API 렌더링 특성:**
   - 텔레그램 메시지는 HTML 태그 중 `<font color="...">`나 인라인 CSS 스타일을 지원하지 않으므로, 색상 표현은 **유니코드 표준 컬러 이모지**를 사용해야 합니다.
2. **완벽한 크기 및 폰트 너비 일치:**
   - `🟨` (Yellow Large Square, U+1F7E8)와 `⬛` (Black Large Square, U+2B1B)는 유니코드 상 동일한 패밀리의 블록 이모지로, **모바일과 PC 모든 화면에서 크기와 줄 간격이 100% 일치**하여 게이지 바가 흐트러지지 않습니다.
3. **가시성(Visibility) 극대화:**
   - **체결 완료 차수:** 선명한 **노란색 네모(`🟨`)** (LED가 켜진 상태)
   - **미진행 빈칸 차수:** 차분한 **검정색 네모(`⬛`)** (슬롯이 비어있는 상태)
   - 텔레그램 다크 모드 및 라이트 모드 모두에서 노란색이 가장 또렷하게 부각됩니다.

## 4. 구현 세부 설계 (Implementation Details)

### 4-1. 전용 헬퍼 함수 (`utils/formatters.py`)
```python
def format_progress_single_track(
    dummy_count: int,
    executed_units: int,
    max_dummy: int = 2,
    max_units: int = 10,
    filled_char: str = "🟨",  # 노란색 네모 (완료)
    empty_char: str = "⬛",   # 검정색 네모 (빈칸)
    include_counts: bool = True
) -> str:
    """
    노란색(완료)과 검정색(빈칸)의 고대비 색상 조합으로 단일 트랙 차수 인디케이터를 생성합니다.
    출력 예: [더미: 🟨⬛ ┆ 실제: ⬛⬛⬛⬛⬛⬛⬛⬛⬛⬛] (더미 1/2, 실제 0/10)
    """
    d_count = min(max(dummy_count, 0), max_dummy)
    u_count = min(max(executed_units, 0), max_units)

    dummy_boxes = (filled_char * d_count) + (empty_char * (max_dummy - d_count))
    unit_boxes = (filled_char * u_count) + (empty_char * (max_units - u_count))

    bar = f"[더미: {dummy_boxes} ┆ 실제: {unit_boxes}]"
    if include_counts:
        return f"{bar} (더미 {d_count}/{max_dummy}, 실제 {u_count}/{max_units})"
    return bar
```
